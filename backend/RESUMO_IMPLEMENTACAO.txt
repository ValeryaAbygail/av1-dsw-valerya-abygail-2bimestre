🎮 CONTROLLER - TAREFACONTROLLER.JS
═══════════════════════════════════════════════════════════════════════════════
  
  ✅ listarTarefas(req, res)
     └─ GET /tarefas
     └─ Retorna: {sucesso, quantidade, dados}
  
  ✅ obterTarefa(req, res)
     └─ GET /tarefas/:id
     └─ Valida ID
     └─ Retorna 404 se não encontrar
  
  ✅ criarTarefa(req, res)
     └─ POST /tarefas
     └─ Valida campos obrigatórios
     └─ Retorna 201 Created
     └─ Trata erros com 400
  
  ✅ atualizarTarefa(req, res)
     └─ PUT /tarefas/:id
     └─ Valida ID
     └─ Aceita campos opcionais
     └─ Retorna 404 se não encontrar
  
  ✅ excluirTarefa(req, res)
     └─ DELETE /tarefas/:id
     └─ Valida ID
     └─ Retorna 404 se não encontrar

  GET    /tarefas          → Listar todas
  GET    /tarefas/:id      → Buscar por ID

  DELETE /tarefas/:id      → Excluir

🗂️ SCHEMA PRISMA
═══════════════════════════════════════════════════════════════════════════════
  
  Model Task:
    ✅ id (Int) - PK, autoincrement
    ✅ title (String) - Obrigatório
    ✅ description (String) - Opcional
    ✅ completed (Boolean) - Default: false
    ✅ createdAt (DateTime) - Default: now()
    ✅ updatedAt (DateTime) - Auto atualizado
    ✅ categoryId (Int) - FK, Optional
    ✅ category (Category) - Relacionamento
  
  Model Category:
    ✅ id (Int) - PK, autoincrement
    ✅ name (String) - Unique
    ✅ tasks (Task[]) - Relacionamento

📋 VALIDAÇÕES IMPLEMENTADAS
═══════════════════════════════════════════════════════════════════════════════
  
  CREATE (POST):
    ✅ title: obrigatório, string não vazia
    ✅ description: opcional, string
    ✅ categoryId: opcional, número válido
  
  READ (GET):
    ✅ id: número válido
    ✅ 404 se não encontrar
  
  UPDATE (PUT):
    ✅ id: número válido
    ✅ title: string não vazia (se fornecido)
    ✅ description: string (se fornecido)
    ✅ completed: boolean (se fornecido)
    ✅ categoryId: número válido ou null (se fornecido)
  
  DELETE:
    ✅ id: número válido
    ✅ 404 se não encontrar
