🚀 COMO USAR - PASSO A PASSO
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Instalar Dependências
  Windows:  Execute install.bat ou abra cmd em backend/ e rode: npm install
  Linux/Mac: npm install

PASSO 2: Testar Conexão com Banco
  npm run db:test
  
  Deve exibir:
    ✅ Conexão bem-sucedida com o banco de dados!
    📊 Tarefas no banco: X
    📂 Categorias no banco: Y

PASSO 3: Iniciar Servidor
  Desenvolvimento (com auto-reload):  npm run dev
  Produção:                           npm start

PASSO 4: Testar a API (3 Opções)

  Opção A - Teste Automatizado:
    npm run test:crud
    (Vai executar create, read, update, delete automaticamente)

  Opção B - Importar no Insomnia/Postman:
    1. Abrir Insomnia/Postman
    2. Import → Selecionar insomnia_collection.json
    3. Clicar nas 5 requisições pré-configuradas

  Opção C - Usar curl (Terminal/PowerShell):
    curl http://localhost:3000/tarefas


📊 EXEMPLOS DE REQUISIÇÃO
═══════════════════════════════════════════════════════════════════════════════

1. LISTAR TODAS AS TAREFAS
   GET http://localhost:3000/tarefas
   
   Resposta (200):
   {
     "sucesso": true,
     "quantidade": 2,
     "dados": [...]
   }

2. BUSCAR TAREFA POR ID
   GET http://localhost:3000/tarefas/1
   
   Resposta (200):
   {
     "sucesso": true,
     "dados": {...}
   }
   
   Erro (404):
   {
     "sucesso": false,
     "erro": "Tarefa não encontrada"
   }

3. CRIAR NOVA TAREFA
   POST http://localhost:3000/tarefas
   Content-Type: application/json
   
   {
     "title": "Estudar Prisma",
     "description": "Aprender o ORM Prisma",
     "categoryId": 1
   }
   
   Resposta (201):
   {
     "sucesso": true,
     "mensagem": "Tarefa criada com sucesso",
     "dados": {...}
   }

4. ATUALIZAR TAREFA
   PUT http://localhost:3000/tarefas/1
   Content-Type: application/json
   
   {
     "title": "Estudar Prisma Advanced",
     "completed": true
   }
   
   Resposta (200):
   {
     "sucesso": true,
     "mensagem": "Tarefa atualizada com sucesso",
     "dados": {...}
   }

5. EXCLUIR TAREFA
   DELETE http://localhost:3000/tarefas/1
   
   Resposta (200):
   {
     "sucesso": true,
     "mensagem": "Tarefa excluída com sucesso",
     "dados": {...}
   }

   DATABASE_URL="mysql://root:senha@localhost:3306/db_nome"

   - Verifique DATABASE_URL em .env
   - Verifique se o banco existe
