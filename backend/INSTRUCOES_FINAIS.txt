🎯 COMO USAR
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Instalar Dependências
  
  Windows (GUI):  Execute install.bat
  Terminal:       npm install

PASSO 2: Testar Conexão com Banco
  
  npm run db:test
  
  Você verá:
    ✅ Conexão bem-sucedida com o banco de dados!
    📊 Tarefas no banco: X
    📂 Categorias no banco: Y

PASSO 3: Iniciar Servidor
  
  Desenvolvimento (com auto-reload):  npm run dev
  Produção:                           npm start
  
  Você verá:
    ✅ Conexão bem-sucedida com o banco de dados!
    🚀 Servidor rodando em http://localhost:3000

PASSO 4: Testar a API
  
  Opção A - Testes Automatizados:
    npm run test:crud
  
  Opção B - Importar no Insomnia/Postman:
    Abrir → Import → insomnia_collection.json
  
  Opção C - Usar curl:
    curl http://localhost:3000/tarefas


🧪 EXEMPLOS DE REQUISIÇÃO
═══════════════════════════════════════════════════════════════════════════════

1️⃣  LISTAR TODAS AS TAREFAS
    GET http://localhost:3000/tarefas
    
    Resposta (200):
    {
      "sucesso": true,
      "quantidade": 2,
      "dados": [...]
    }

2️⃣  BUSCAR TAREFA POR ID
    GET http://localhost:3000/tarefas/1
    
    Resposta (200):
    {
      "sucesso": true,
      "dados": {...}
    }
    
    Erro (404):
    {
      "sucesso": false,
      "erro": "Tarefa não encontrada"
    }

3️⃣  CRIAR NOVA TAREFA
    POST http://localhost:3000/tarefas
    Content-Type: application/json
    
    {
      "title": "Estudar Prisma",
      "description": "Aprender ORM",
      "categoryId": 1
    }
    
    Resposta (201):
    {
      "sucesso": true,
      "mensagem": "Tarefa criada com sucesso",
      "dados": {...}
    }

4️⃣  ATUALIZAR TAREFA
    PUT http://localhost:3000/tarefas/1
    Content-Type: application/json
    
    {
      "title": "Novo Título",
      "completed": true
    }
    
    Resposta (200):
    {
      "sucesso": true,
      "mensagem": "Tarefa atualizada com sucesso",
      "dados": {...}
    }

5️⃣  EXCLUIR TAREFA
    DELETE http://localhost:3000/tarefas/1
    
    Resposta (200):
    {
      "sucesso": true,
      "mensagem": "Tarefa excluída com sucesso",
      "dados": {...}
    }

📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Erro: "Connection refused"
  → MySQL não está rodando
  → Verifique DATABASE_URL em .env

Erro: "ENOENT: no such file"
  → Execute: npm run prisma:generate

Erro: "Port 3000 already in use"
  → Altere PORT em .env

Erro: "database does not exist"
  → Crie o banco manualmente ou execute migrações
