🏗️ ARQUITETURA IMPLEMENTADA
═══════════════════════════════════════════════════════════════════════════════

Padrão MVC:
  ├─ Model Layer (tarefaModel.js)
  │  ├─ listar()
  │  ├─ buscarPorId(id)
  │  ├─ criar(dados)
  │  ├─ atualizar(id, dados)
  │  └─ excluir(id)
  │
  ├─ Controller Layer (tarefaController.js)
  │  ├─ listarTarefas(req, res)
  │  ├─ obterTarefa(req, res)
  │  ├─ criarTarefa(req, res)
  │  ├─ atualizarTarefa(req, res)
  │  └─ excluirTarefa(req, res)
  │
  └─ Routes Layer (tarefaRoutes.js)
     ├─ GET /tarefas
     ├─ GET /tarefas/:id
     ├─ POST /tarefas
     ├─ PUT /tarefas/:id
     └─ DELETE /tarefas/:id
